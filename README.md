# survsim

> **`survsim` is no longer developed.** Its successor is [`avalon`](https://reddooranalytics.se/software/avalon/), from Red Door Analytics, for simulating survival data in R and Stata. `avalon` is a complete rewrite with a new syntax, not a new version of `survsim`. This repository is an archive: version 4.0.11 is the final version, and can still be installed as described below.

Simulating time-to-event data in Stata, from parametric distributions, custom distributions, competing risks models and general multi-state models.

For an introductory seminar, see [Simulating time-to-event data from parametric distributions, custom distributions, competing risk models and general multi-state models](https://www.youtube.com/watch?v=hmeE0qPOjP8).

## What it simulates

`survsim` simulates survival times from:

- **A parametric distribution** (`help survsim parametric`): exponential, Gompertz and Weibull, and 2-component mixtures of them, with covariate effects and non-proportional hazards.
- **A user-defined distribution** (`help survsim user`): any hazard or cumulative hazard function, on the natural or the log scale, written in Mata; survival times are generated by numerical integration and root finding.
- **A fitted `merlin` model** (`help survsim model`).
- **A competing risks or general multi-state model** (`help survsim msm`): each transition has its own hazard function, a standard distribution or a user-defined one, with its own covariates and time-dependent effects.

## Requirements

- Stata 14.2 or later
- `moremata`, for user-defined distributions and multi-state models: `ssc install moremata`
- `merlin` and `multistate`, to simulate from a fitted `merlin` model: `ssc install merlin` and `ssc install multistate`

## Installation

`survsim` can be installed from the SSC archive by typing:

```stata
ssc install survsim
```

To install directly from this GitHub repository, use:

```stata
net install survsim, from("https://raw.githubusercontent.com/mjcrowther/survsim/main/")
```

## Example

Survival times from a Weibull distribution, with a binary treatment that has a log hazard ratio of -0.5, and censoring at 5 years:

```stata
clear
set obs 1000
gen trt = rbinomial(1,0.5)
survsim stime died, distribution(weibull) lambdas(0.1) gammas(1.5) covariates(trt -0.5) maxtime(5)
stset stime, failure(died = 1)
streg trt, distribution(weibull) nohr
```

Further examples, including competing risks and multi-state models, are in the help files: `help survsim`.
